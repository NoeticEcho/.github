# Contributing

Thank you for looking. Each repository's README says how to build and test it; the short version for all of them:

- Open an issue before a large change, so we can agree on the shape first.
- One change per pull request, with a test that fails without it.
- Say what you checked and how. "It works on my machine" with the command you ran is better than "it works".
- Be kind. The [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) is our code of conduct; report problems privately to conduct@noeticecho.space.
